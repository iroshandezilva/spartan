Reference study · tables & filters

A reusable system for working with records.

Attio table and filter patterns, rebuilt as reusable Spartan components. This report records the delivered library, verified source interactions, design-token exceptions and the limits of the prototype.

Open Attio page in Figma ↗Open the prototype ↗
28 component families delivered, with structural and visual checks.

The listed source interactions were inspected in the signed-in ss-5-sg Companies workspace through Dia. Temporary filters were discarded and the original view restored; no records were altered. The Figma build uses synthetic sample data. Its navigation was checked structurally, without a full traversal in the Figma player.

04

Validation boundary

  • Live coverage is limited to the described controls in the ss-5-sg Companies view. Other objects, permissions, custom attributes, multi-record action differences and workspace-wide states are not established.
  • Official screenshots provide selected visual references. They do not establish exhaustive variants or current interaction timing.
  • Exact measurements, token mappings, keyboard focus, menu dismissal, selection precedence, error feedback and animations need their own checks. Observing a control is not evidence that its action was executed.
  • Live inspection resolves the saving ambiguity in the documentation: the tested filter exposed explicit save and discard controls, and discard restored the original view. The save operation was not performed.
  • Workflow comparison documentation is not a table-filter specification. The inspected numeric field had strict comparisons but no inclusive comparisons; the live operator inventory above is the source for this component.
  • The Figma audit checked component structure, token bindings, icon configuration, content-slot constraints and valid navigation destinations. Screenshot review checked presentation. It did not include a full live traversal in the Figma prototype player.
  • The build contains six synthetic sample companies. Query results, sorting and saving are fixed examples; the prototype does not evaluate arbitrary values or persist data. Supplemental states are marked in the delivered-coverage section.
