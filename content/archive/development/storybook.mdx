## Planned setup

Use `@storybook/web-components-vite` to render Lit components directly. This hub does not yet include an operational Storybook workspace; its setup task is open.

## Story coverage

For each component, show supported appearances and sizes, disabled and loading states where applicable, themes, density, keyboard behavior, and long-content examples. State controls should operate the actual component properties.

## Documentation integration

Fumadocs pages will embed or link to the matching Storybook story. Keep one implementation and one set of examples. Do not recreate the component in React just to document it.

## Acceptance

Storybook setup is complete when a real Lit component loads, controls work, generated tokens are applied, and its example can be opened from this hub. Browser interaction checks and visual review are distinct from a successful static build.

[Official Web Components integration](https://storybook.js.org/docs/get-started/frameworks/web-components-vite)
