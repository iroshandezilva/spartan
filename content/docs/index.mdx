Spartan is a code-owned design system. The components are Lit Web Components, the design tokens are generated from the Spartan DS Figma variables, and Storybook is the interactive playground.

<Callout title="What this site covers">
This site documents how to use what exists today: the generated tokens, theming modes, and the components that have shipped (`sp-button` and `sp-icon-button`). Pages describe implemented behavior only. Task tracking, project decisions, and workflow documents live in [Linear](https://linear.app/wearehaux/document/spartant-design-system-project-home-5730425b4e0d).
</Callout>

## Start here

- [Getting started](/docs/getting-started): install, load the tokens, and render a first component.
- [Foundations](/docs/foundations): the token collections, colors, typography, spacing, radii, and density.
- [Theming](/docs/theming): switch Semantic Color, Primary hue, and Density with mode attributes.
- [Components](/docs/components): the component reference, starting with [Button](/docs/components/button).
