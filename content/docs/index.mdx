## Start here

This experiment explores a code-owned component system using Lit, with Figma as an editable design companion. This hub records decisions, explains the workflow, and tracks implementation without treating an old screenshot as proof of completion.

- [Task manager](/docs/project/tasks): edit development and Figma progress.
- [Local setup](/docs/project/setup): run the hub and build the plugin.
- [Architecture](/docs/architecture): understand each tool's responsibility.
- [Token contract](/docs/sync/token-contract): understand the initial sync format.

## What exists today

The local Fumadocs hub, task file, token build, and initial custom plugin source are implemented. The seed token file is a small, isolated fixture, not an export of the production Figma library. The plugin must pass a real Figma import and binding check before its task is marked Done. Lit component and Storybook implementation remain tracked work.
