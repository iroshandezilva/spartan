Every component is a Lit Web Component, registered as a custom element with an `sp-` prefix. Each has a Figma master set and a Storybook playground.

| Component | Element | Reference |
| --- | --- | --- |
| Button | `<sp-button>` | [Button](/docs/components/button) |
| Icon Button | `<sp-icon-button>` | [Icon Button](/docs/components/icon-button) |

<Callout title="Scope">
Only components with code in `packages/components` are listed. Further component pages are tracked in Linear and follow the same page structure: [component page template](https://github.com/iroshandezilva/spartan/blob/dev/content/templates/component-page.mdx).
</Callout>
