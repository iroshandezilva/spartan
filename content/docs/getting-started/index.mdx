---
title: Getting started
description: What you need to use Spartan components and tokens in a page.
---

Using Spartan takes two things: the generated design-token stylesheet and the component package. Components read only `--sp-*` CSS variables, so without the stylesheet they render unstyled.

1. [Install and load the tokens](/docs/getting-started/installation).
2. [Render your first component](/docs/getting-started/first-component).
3. Read [Theming](/docs/theming) to switch style, color scheme, contrast, hue, and density.

<Callout type="warn" title="Not published to npm yet">
`@spartan/components` is a private workspace package in the Spartan repository. There is no public npm release, so the steps below apply to code inside this repository.
</Callout>
