## Spacing

Layout spacing uses semantic tokens that alias the space primitives.

| Token | Use |
| --- | --- |
| `--sp-space-surface-padding` | Padding inside a card or panel |
| `--sp-space-stack-gap` | Gap between stacked items |
| `--sp-space-section-gap` | Gap between page sections |

Primitives run on a 4px step, for example `--sp-prim-space-1` (4px), `-2` (8px), `-4` (16px), `-6` (24px), and `-12` (48px).

## Radius

| Token | Use |
| --- | --- |
| `--sp-radius-control` | Buttons and inputs |
| `--sp-radius-surface` | Cards and panels |
| `--sp-radius-pill` | Fully rounded ends |
| `--sp-radius-drawer` | Drawers |

## Border width

`--sp-border-width-default` is 1px in Light and Dark and 2px in the two high contrast modes.
